## Why not just sort by stars?

Star counts measure accumulated attention; **PopScore measures current momentum**. The formula combines five factors: star velocity (35%), fork-to-star engagement ratio (20%), code activity such as merged PRs and issue close rate (25%), external community mentions on Hacker News and Reddit (10%), plus a noise filter that down-ranks content-only repositories like list repos and tutorial collections (10%). The full formula is public and pinned by unit-test fixtures — see the [methodology page](https://gitpop.com/methodology).

## How this list works

- **Auto-generated**: a scheduled job snapshots every tracked project daily and recomputes scores. Every Monday, this README is rebuilt and committed by a bot.
- **Data provenance**: all metrics come from public GitHub APIs plus HN/Reddit mention counts via public search endpoints.
- **Not accepting PRs to the table** — it would be overwritten by the next run. If something looks wrong, please open an issue instead.
